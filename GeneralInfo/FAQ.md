# Frequently Asked Questions

- **คำถาม** ความยากง่ายของเนื้อหาอยู่ในระดับใด หากต้องการศึกษาต่อในเชิงลึก สามารถศึกษาได้ที่ไหน
  
    - Brain Code Camp ถูกออกแบบมาให้ทำหน้าที่เหมือน Missing Semester ในโลกของ Machine Learning และ Computational Neuroscience โดยหลักสูตรต้องการให้ผู้เรียนได้เรียนรู้เทคนิคพื้นฐานทาง machine learning และ signal processing ที่ควรรู้จัก​​ ซึ่งเป็นรากฐานของเทคนิคใหม่ ๆ ทาง computational neuroscience โดยหวังว่าการศึกษาจากเนื้อหาเหล่านี้จะทำให้ผู้เรียนมีความรู้พื้นฐานที่เพียงพอต่อการนำไปต่อยอดศึกษาเทคนิคที่มีความซับซ้อนที่พบเจอได้ตามผลงานตีพิมพ์ทางวิชาการได้

      ทีมงานประเมินความลึกของเนื้อหาใน Brain Code Camp ที่ระบุไว้ใน [schedule](./schedule.md) ดังนี้
      - ด้าน AI: ยากไม่เกินกว่าคอร์ส Introduction to Machine Learning ตามหลักสูตรวิศวกรรมศาสตร์/วิทยาศาสตร์คอมพิวเตอร์ทั่วไป ที่เน้นไปที่ความเข้าใจ concept ของเทคนิคและการนำเทคนิคเหล่านั้นไปใช้งาน มากกว่ารายละเอียดเชิงลึกทางคณิตศาสตร์หรือทฤษฎี เพื่อให้ผู้ที่มีพื้นฐาน programming ในระดับนึงสามารถเข้าไปเรียนรู้เนื้อหาได้ โดยไม่ต้องมีพื้นฐานทางสถิติหรือคณิตศาสตร์ขั้นสูง
        - ทีมงานคิดว่าเนื้อหาใน Brain Code Camp จะช่วยเตรียมความพร้อมในทาง concept ให้แก่ผู้ที่ต้องการไปเรียนวิชา machine learning ในระดับที่สูงขึ้นได้
        - ในแพลตฟอร์มจะมีเนื้อหาที่ระบุไว้ว่าเป็น optional ซึ่งจะมีคณิตศาสตร์หรือสถิติเพิ่มเติมเข้ามาสำหรับผู้ที่สนใจ
        - หากต้องการต่อยอดทางด้าน AI ผู้เรียนสามารถ
          - ศึกษาเนื้อหา Extra Lectures ของ Brain Code Camp
          - ลงเรียน course และฟัง talk จากมหาวิทยาลัยหรือสถาบันต่าง ๆ
          - อ่าน textbook และ paper ใน conference ต่าง ๆ
      - ด้าน computational neuroscience: นอกเหนือไปจากเนื้อหาทางด้าน AI แล้ว เนื้อหาใน Brain Code Camp ยังครอบคลุม concept ที่ควรรู้เกี่ยวกับการทำ signal processing (เช่น sampling, averaging, Fourier transform และ filtering) และ การประมวลผลข้อมูลทางประสาทวิทยาศาสตร์เบื้องต้น (เช่น fMRI, EEG และ spiking)
        - หากต้องการศึกษาต่อยอดทางด้านนี้ ผู้เรียนสามารถ
          - ศึกษาเนื้อหาจาก Neuromatch Academy (NMA) ประกอบด้วย
            - [Computational Neuroscience](https://compneuro.neuromatch.io/)
            - [NeuroAI](https://neuroai.neuromatch.io/) ซึ่งมีคอร์ส [Deep Learning](https://deeplearning.neuromatch.io/) ของ NMA เป็น pre-req ด้วย
          - ลงเรียน course และฟัง talk จากมหาวิทยาลัยหรือสถาบันต่าง ๆ
          - อ่าน textbook และ paper ใน journal และ conference ต่าง ๆ

- **คำถาม** สามารถนำเอา project ที่ได้ทำในกิจกรรม Brain Code Camp ไปใช้เป็นส่วนหนึ่งของ graduation requirements ของสถานศึกษาหรือสถาบันได้หรือไม่

  - ถ้าหากไม่ขัดกับกฎระเบียบของสถานศึกษาหรือสถาบันที่ท่านสังกัดอยู่ ทีมงานอนุญาตให้ท่านนำเอา project ที่ท่านทำ ไปใช้เป็นส่วนหนึ่งของ graduation requirements ของท่านได้

- **คำถาม** ถ้าหากไม่สะดวกเข้าร่วม office hours ในบางสัปดาห์ เนื่องจากติดภารกิจใด ๆ (เช่น ติดสอบ) ควรทำอย่างไร
  - ถ้าหากไม่สะดวกเข้าร่วม office hour ในสัปดาห์ไหน ขอให้ท่านแจ้งผู้ช่วยสอน (TA) และ อัพเดตกับ TA นอกรอบ เพื่อให้ทีมงานช่วยติดตามและช่วยเหลือท่านได้ อย่างไรก็ตามทีมงานขอให้ท่านเข้า office hours ให้มากที่สุดเท่าที่ทำได้ และลาเฉพาะเวลาที่จำเป็นจริง ๆ

- **คำถาม** ถ้าหากไม่สะดวกเข้าร่วมงาน [on-site meetups](./on-site-meetups.md) ควรทำอย่างไร
  - งาน On-Site Meetups เป็นงาน optional (ไม่ได้บังคับให้เข้าร่วม) ที่มีจุดมุ่งหมายหลักคือการให้ผู้เข้าร่วมโครงการ Brain Code Camp ได้มาทำความรู้จักกัน หากไม่สะดวกเข้าร่วมแบบ on-site สามารถเข้าร่วมบางกิจกรรมแบบออนไลน์ได้ อย่างไรก็ตาม การไม่เข้าร่วมงาน on-site meetups จะไม่ส่งผลกระทบต่อการพิจารณาได้รับประกาศนียบัตรใด ๆ

- **คำถาม** ถ้าหากเคยเข้าร่วม Brain Code Camp ในปีก่อนหน้า จะยังสามารถสมัครเข้าร่วมในปีนี้ได้หรือไม่
  - สามารถเข้าร่วมอีกครั้งได้ แต่จะมีเกณฑ์การพิจารณาที่ยากขึ้นกว่าผู้สมัครที่สมัครเข้ามาเป็นครั้งแรก โดยผู้สมัครที่ต้องการมาเข้าซ้ำ นอกจากจะต้องทำคะแนนให้ได้สูงกว่าผู้สมัครที่มาเป็นครั้งแรกแล้ว จะถูกพิจารณาเปรียบเทียบเพิ่มเติมกับผู้สมัครที่ต้องการมาเข้าซ้ำด้วยกัน
  - ทีมงานขอยืนยันว่า การที่มีผู้สมัครบางคนมาเข้าร่วม Brain Code Camp อีกครั้ง จะไม่เป็นการไปแย่งที่ของผู้สมัครคนอื่นที่สมัครมาเป็นครั้งแรก เช่น ถ้าหากเดิมมีโควต้ารับผู้สมัคร 50 คน ผู้สมัครที่สมัครมาเข้าซ้ำที่ผ่านการคัดเลือกจะถูกนับเป็นคนที่ 51

- **คำถาม** ทีมงานมีทรัพยากรการคำนวณส่วนตัวให้แก่ผู้เรียนทุกคนหรือไม่
  - ทีมงานไม่มีทรัพยากรการคำนวณเฉพาะให้ แต่ผู้เรียนทุกคนจะยังสามารถเรียนรู้และทำทุกแบบฝึกหัดได้อย่างไม่มีข้อจำกัดผ่าน Google Colab ได้
